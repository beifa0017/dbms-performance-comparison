# 实验数据

- `movies.csv`、`people.csv`：课程原规模导出，电影9204条、人物16489条。
- `*-10x.csv`、`*-50x.csv`：报告使用的十倍、五十倍数据，扩充时给标题和姓名加了区分后缀。
- 六份 CSV 都没有表头，不用重新生成。
- IMDb 的 `title.basics.tsv` 通过根目录下载脚本从[官方网站](https://datasets.imdbws.com/)获取，不随仓库转载。[使用条款](https://help.imdb.com/article/imdb/general-information/can-i-use-imdb-data-in-my-software/G5JTRESSHJBBHTGX)
