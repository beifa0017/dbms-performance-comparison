# 实验数据

- `movies.csv`、`people.csv`：课程原规模导出，电影9204条、人物16489条。
- `*-10x.csv`、`*-50x.csv`：报告使用的十倍、五十倍数据，扩充时给标题和姓名加了区分后缀。
- 六份 CSV 都没有表头，不用重新生成。
- IMDb：[下载 title.basics.tsv.gz](https://datasets.imdbws.com/title.basics.tsv.gz)，解压后把 `title.basics.tsv` 放在本目录。官方每日更新，数量可能与报告略有不同；数据不随仓库转载。[使用条款](https://help.imdb.com/article/imdb/general-information/can-i-use-imdb-data-in-my-software/G5JTRESSHJBBHTGX)
